# Submission checklist

- [ ] Read the one-page Game Design Document in README.md.
- [ ] Open index.html in a browser and test the game.
- [ ] Test the win condition (15 stars) and the timer/time-up condition.
- [ ] Test Reset and Play again.
- [ ] Create a public GitHub repository named `star-sprint-game`.
- [ ] Upload `index.html` and `README.md`.
- [ ] In GitHub: Settings → Pages → deploy from branch → `main` → `/ (root)` → Save.
- [ ] Wait for GitHub Pages to publish, then open the live URL and test it.
- [ ] Submit one public repository link or live game link, following your task portal's instructions.
